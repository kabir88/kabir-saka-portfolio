# Kabir Saka Olaoluwa | Portfolio

Personal portfolio for a full stack developer based in Mauritius. A single static page covering projects, client work and contact details.

**Live:** https://kabir-saka-portfolio.vercel.app

## Stack

HTML, CSS and JavaScript, deployed as a static site on Vercel.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
